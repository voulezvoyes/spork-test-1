# Spork Test V1

Purpose: usability testing of the branching interaction before backend/API work.

This build intentionally uses local mock AI responses. It does not call Anthropic and does not store user data.

## Deploy
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Import that repository into Vercel.
4. Framework preset should detect Next.js automatically.
5. Deploy. No environment variables are required.

Keep the original `spork-v5.jsx` separately as the pre-validation source artifact.
